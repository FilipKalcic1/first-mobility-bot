## What actually happened (honest report)

**Sample audit was substantially degraded by LLM JSON parse failures.**

- 50 tools attempted

Root cause of JSON parse failures: `max_tokens=600` insufficient for batched 30-anchor classifications, output got truncated mid-JSON. Response format guard prevented retry on parse failure.

## Honest finding

The F2 audit claim of "24% anchor noise" (per `docs/AUDIT_FINDINGS_2026-05-09.md`) is **not corroborated** by this sample, but:

1. Sample size (45 successful classifications) is statistically too small to confirm or refute 24%.
2. JSON parse failures concentrated on long-anchor-list tools — those are exactly the tools most likely to have noise.
3. 0 hallucinations in clean sub-sample could mean (a) anchors are already clean, OR (b) gpt-4o-mini's classification is too lenient on borderline anchors.

**Cannot reliably validate anchor quality from this run.**
