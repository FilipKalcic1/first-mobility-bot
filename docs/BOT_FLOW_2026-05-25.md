# Kako bot teče — provjeren flow (2026-05-25)

Canonical referenca kako poruka teče kroz bota **danas** (nakon reset-a filtera, commit `8f9ba4d`). Grounded u kodu (file + simbol; brojevi linija se mijenjaju pa ih ne citiram). **Filter trenutno NE postoji** — to je jasno označeno gdje bi išao.

---

## Dvije staze

Nakon identifikacije + guarda, upit ide jednom od dvije staze:

- **Staza A — driver self-pitanja** ("koja mi je km", "koji je moj auto", "registracija"): brzi shortcut, **bez** pickera/params/filtera.
- **Staza B — sve ostalo** ("obriši rezervaciju 45", "lista vozila", "dodaj km"): puni 3-turn cascade.

```
WhatsApp poruka
  │
  ├─[guards]  rate-limit → PII-scrub → sanitizer → IDENTITY → crisis →
  │           negation → multi-intent → meta → special-intents → unknown-phone
  │           (identity.resolve → /Persons + /MasterData, REZULTAT CACHED)
  │
  ├─[L2a] intent klasifikacija (LLM)
  │
  ├─► STAZA A: ako = "pitanje o sebi" + poznat user
  │     L2b driver_basics (embedding) → cached MasterData → field_hint →
  │     L8 formatter izvuče polje → WhatsApp.   [0 novih API poziva]
  │
  └─► STAZA B: sve ostalo  (Model A, 3 turna)
        Turn 1  action-pick:  POGLEDATI/UNIJETI/IZMIJENITI/IZBRIŠI
        Turn 2  scope → cosine top-50 → LLM tool-call → top-3 picker (s opisima)
        Turn 3  param-resolucija → mutation-confirm → execute → format → WhatsApp
```

---

## Staza A — driver self-basics (shortcut)

Za pitanja o vlastitim podacima. Kod: [services/v2/driver_basics.py](services/v2/driver_basics.py).

1. **L2b prepozna** "user pita za vlastite podatke" — **embeddingom** (značenje), uz keyword-fallback ako embedder padne. Nije kruti regex.
2. **MasterData je VEĆ dohvaćen** pri identifikaciji (L0, `identity.resolve` → `GET /MasterData?personId=…`) i **cached**. To je composite zapis (~75 polja: vozilo, km, registracija, leasing, CO2, istek…). **Nema novog API poziva.**
3. **`field_hint`** (npr. "vozilo") se proslijedi **formatteru** (`format_response` u [services/v2/formatter.py](services/v2/formatter.py), koji koristi L8 `LLMFormatter` iz [services/formatter/llm_formatter.py](services/formatter/llm_formatter.py)) — on dinamički izvuče traženo polje iz tih 75 ključeva.
4. Formatirano → WhatsApp.

**Nema:** action-pickera, tool-pickera, param-unosa, filtera. Sve to se za ovaj tip upita **preskače**.

## Staza B — opći 3-turn cascade (Model A)

Kod: [services/v2/engine.py](services/v2/engine.py) (`_dispatch_message`, `_resolve_pending_clarify`).

### Turn 1 — action-pick
Pitamo korisnika koju vrstu radnje želi (suzi na HTTP metodu). Labele iz [services/v2/clarify_ui.py](services/v2/clarify_ui.py) (`ACTION_LABELS`):
| Korisnik vidi | HTTP metoda |
|---|---|
| POGLEDATI | GET |
| UNIJETI / KREIRATI | POST |
| IZMIJENITI | PUT + PATCH |
| IZBRISATI | DELETE |

### Turn 2 — tool-pick (od 950 → 1)
[services/router/catalog_scoper.py](services/router/catalog_scoper.py) → [anchor_index.py](services/router/anchor_index.py) → [llm_router.py](services/router/llm_router.py):
1. **scope:** tenant subset → persona → izabrana metoda → drop_internal.
2. **anchor cosine top-50:** semantička sličnost upita s anchorima.
3. **LLM tool-call:** gpt-4o-mini bira + hallucination-check (mora biti u top-50).
4. **top-3 picker:** korisniku se prikažu **3 kandidata s kratkim opisom**; bira jedan.

### Turn 3 — param-resolucija → confirm → execute → format
1. **Param-resolucija** (3 načina, vidi dolje).
2. **`[FILTER]`** — *trenutno NE postoji* (vidi sekciju Filter).
3. **mutation-confirm** ([services/v2/mutation_gate.py](services/v2/mutation_gate.py)): DELETE uvijek; POST/PUT/PATCH ako kritično → "Da/Ne".
4. **execute** ([services/v2/executor.py](services/v2/executor.py)): HTTP poziv + x-tenant + Idempotency-Key (mutacije) + circuit breaker.
5. **format** (L8 formatter, `field_hint`) → WhatsApp. 4xx → [api_error_translator.py](services/v2/api_error_translator.py) prevede u HR.

---

## Param-resolucija — 3 načina (+ coercion)

Za svaki parametar izabranog toola (definiran u `config/tool_data.json`):

| Način | Kako | Kod |
|---|---|---|
| **AUTO (context-inject)** | identitetska vrijednost (vehicle/person/tenant/company/orgunit) ubaci se sama | `executor` (`context_params` → identity) |
| **IZVUČE (LLM)** | LLM izvuče **izrečene** vrijednosti iz poruke ("45", "30500") — `required:[]` pa NE izmišlja | `llm_router` |
| **PITA** | required koji fali → bot pita korisnika (jedan po jedan, HR labela) | `engine._compute_missing_required` + [param_ui.py](services/v2/param_ui.py) |

**Coercion** (format): int (strip ne-znamenke), HR-decimal (`,`→`.`), bool ("da/ne"), datum ("sutra 9:00"→ISO). **Anti-fabrikacija:** LLM puni samo izrečeno; ako ne zna → pita ili (za required context koji se ne može popuniti) **odbije**, nikad ne šalje izmišljeno.

## Output-selekcija (koju vrijednost prikazati)

Tool vrati response s puno polja (MasterData ~75). **`field_hint`** (postavljen kad se pickne kandidat / u driver_basics) usmjeri **L8 formatter** da izvuče/prikaže relevantno (npr. samo vozilo). Za liste: top-N redaka + total. Bot ne "pogađa" što je važno na slijepo — `field_hint` + formatter to vode.

---

## Filter — TRENUTNO NULA

Auto-filter feature je **uklonjen** (commit `8f9ba4d`). Trenutno bot **ne gradi nikakav `Filter`**.
- **Što je bilo:** detekcija registracije → `LicencePlate(=)DA533` → confirm → execute (jedno polje, operator `(=)`).
- **Zašto maknuto:** redizajn iz čiste ploče; polja/operatori/format po kojima se smije filtrirati su **schema-znanje M1 backenda** (vidi `docs/BACKEND_SWAGGER_REQUESTS_2026-05-24.md` — ali filter je iz njega namjerno izbačen dok se ne dogovori).
- **Bitno:** `get_MasterData` **ionako NEMA `Filter` param** — scope je preko `personId` (auto). Filter se tiče samo **list-tool-ova** (266 ih ima `Filter` param), a taj dio se redizajnira.
- **Gdje bi išao:** Turn 3, prije mutation-confirma (vidi `[FILTER]` gore).

## Worked example: "Koji je moj auto?"

1. Guards prođu; identity već razriješen, **MasterData cached**.
2. L2a: "pitanje o sebi" + poznat user.
3. **Staza A:** L2b driver_basics embedding-match.
4. `field_hint = "vozilo"` → L8 formatter izvuče `FullVehicleName` iz cached MasterData.
5. Odgovor: *"Tvoj auto je Škoda Octavia (DA533)."*

**Ukupno: 0 novih API poziva, 0 params, 0 filtera, 0 pickera.** Samo prepoznavanje + formatiranje iz već dohvaćenog zapisa.

## Guards (prije routinga, ukratko)
Redom u `_dispatch_message`: rate-limit → PII-scrub → input-sanitizer → **identity** (resolve TKO si + cache MasterData) → crisis → standalone-negation → multi-intent → meta-intent ("tko si ti") → special-intents (welcome/GDPR/handover) → unknown-phone gate. Tek onda L2a/L2b/Model A.
